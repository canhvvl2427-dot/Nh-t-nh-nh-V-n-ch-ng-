# Nhặt Nhạnh Văn Chương — bản tích hợp lối vào cộng đồng

- Đã sửa URL Supabase trong `cong-dong.html` về URL gốc của project.
- Đã bỏ dấu Markdown ```html bị dính đầu file `index.html`.
- Đã thêm liên kết nổi bật từ trang chủ sang trang cộng đồng.
- Giữ nguyên các trang học Văn hiện có.

## Để đăng bài lưu lâu dài
1. Mở Supabase > SQL Editor.
2. Mở file `SUPABASE_SETUP.sql`, sao chép toàn bộ và chạy.
3. Trên GitHub, tải các file trong thư mục gốc này lên repository (không tải cả thư mục cha lồng vào).
4. Mở `cong-dong.html` trên website và thử đăng bài.

Lưu ý: public posting means anyone can submit content. The SQL grants public SELECT/INSERT only, not UPDATE/DELETE.
